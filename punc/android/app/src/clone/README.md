Coloque aqui o arquivo `google-services.json` do Firebase para o flavor `clone`.

Este app usa o applicationId `com.example.punc.clone`, então o Firebase precisa ter um app Android cadastrado com esse package name.

Passos:
1. No Firebase Console, adicione um app Android usando `com.example.punc.clone`.
2. Baixe o `google-services.json` gerado.
3. Copie ele para esta pasta.
4. Rode `flutter build apk --flavor clone` novamente.
